# Source Decision Log

During the Control Atlas Source Audit (Epic 5/6 transition), the following upstream source ingestion strategies and decisions were made to improve data quality and eliminate fabricated provenance.

| Source or Domain | Issue Detected | Resolution & Decision |
| :--- | :--- | :--- |
| **NIST OLIR Catalog** | Incomplete coverage; hardcoded list of subset artifacts. | **Replaced with Discovery Pipeline**: Implemented a dynamic discovery pipeline (`fetch-olir-mappings.mjs`) that hits the official NIST NUDP API endpoint for the Informative Reference Catalog (`https://csrc.nist.gov/extensions/nudp/services/json/olir/informative-reference-catalog`), fetching the full catalog dynamically. |
| **DISA STIGs and SRGs** | Previously limited to a narrow, hardcoded generic-only allowlist and manually invented manifest data (fake hashes, dates, counts). | **Replaced with Compilation Ingestion**: Dropped the manual allowlist. We now ingest the official quarterly DISA STIG Document Library Compilation archive as the primary source. A strict manifest (`disa-artifact-manifest.json`) is generated directly from the contents, including actual SHA-256 hashes of the compilation, true entry paths, sizes, and record counts. |
| **Vendor/Product STIGs** | Previously excluded by PRD constraints. | **Constraint Lifted**: Re-ingested all applicable, current, publicly available official DISA STIGs, including vendor- and product-specific benchmarks discovered in the compilation. |
| **DISA Lifecycle States** | Historical, superseded, withdrawn, draft, and restricted material were silently treated as current. | **Status Tracking**: The adapter now tags skipped or irrelevant items with proper statuses (`ignored` vs `ingested`) and records the `reason` (e.g., "not an XML/XCCDF file" or "draft") directly from the upstream discovery process rather than estimating. |
| **NIST 800-53B Baselines** | 404 Not Found at `https://github.com/usnistgov/oscal-content/tree/main/nist.gov/SP800-53B-r5` | **Fixed**: NIST restructured the OSCAL repository. The 800-53B baselines are now merged into the main `SP800-53/rev5/json/` folder. The registry URL is updated to `https://github.com/usnistgov/oscal-content/tree/main/nist.gov/SP800-53/rev5/json`. |
| **NIST CSF2 to SP800-171** | 404 Not Found for the draft Excel mapping `Cybersecurity_Framework_v2-0_Concept_Crosswalk_800-171_3_draft.xlsx` | **Updated**: The draft mapping was removed by NIST. The URL is redirected to the authoritative `https://csrc.nist.gov/Projects/olir/informative-reference-catalog` and `retrieval_method` updated to `manual_review`. |
| **DoD Zero Trust PDFs** | 403 Forbidden from `dodcio.defense.gov` | **Acknowledged/No-Action**: DoD websites employ strict Web Application Firewalls (WAF) that block automated crawler requests. The URLs are correct for human browsers, so they remain unchanged. |
| **Manifest Integrity** | Manifest files contained estimated or completely fabricated hashes and publication dates. | **Strict CI Enforcement**: Added `verify:discovery` and `verify:manifests` to the `verify:quality` pipeline. The build now fails if manifests are missing, empty, or lack authentic, computed SHA-256 hashes and accurate identifiers. |
