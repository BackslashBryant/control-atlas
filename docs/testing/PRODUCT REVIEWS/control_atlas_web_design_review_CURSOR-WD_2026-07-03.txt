4. BRAND AND POSITIONING READOUT

---

APPARENT POSITIONING:
Control Atlas positions itself as an open-source, browser-only public reference workbench that maps federal cyber guidance and helps practitioners explore controls, relationships, and blank RMF/ATO templates — explicitly not an official government system or authorization tool.

APPARENT AUDIENCE:
GRC/RMF practitioners, ISSOs, assessors, and technically minded stakeholders who already know terms like AC-2, STIG, CCI, FedRAMP, and RMF — with some onboarding paths for newcomers (Start Here, question-led home cards).

APPARENT BRAND PERSONALITY:
Dark, technical, cartographic, developer-adjacent (keyboard shortcut brand flourish), earnest and disclaimer-forward on trust pages — closer to "open-source compliance map" than "enterprise GRC platform."

PRIMARY VALUE PROPOSITION:
"The public map for federal cyber compliance." + "Explore public controls, baselines, STIGs, and compliance patterns — and generate blank RMF/ATO templates without uploading data or creating an account."

PRIMARY CTA: "Start here" (hero) → #/start

SECONDARY CTA: "Atlas →" (hero) → #/atlas-map

TRUST SIGNALS FOUND:
- Footer: "Control Atlas is an open-source reference tool. It does not replace official guidance. Not an official government system."
- About page WHAT THIS IS NOT bullets and DISCLAIMER block
- Sources page provenance cards (active, public, Used in map: Yes)
- Record detail Primary source: SP 800-53 Rev. 5; Open official source document link
- Home subfooter: "Open-source. No login. Public data only."

SOURCE / METHODOLOGY SIGNALS FOUND:
- Sources registry with canonical links (FISMA, SP 800-53 Rev. 5, ATT&CK, D3FEND)
- Map legend explaining Official mapping / Inferred / Not mapped / Deprecated
- Atlas Map copy referencing list view for screen-reader access

MAIN BRAND GAP:
The visible brand chrome (Ctrl+Alt+{Comply|Map|Navigate|Audit}) does not match the product name "Control Atlas" shown in hero, page title, and About — creating immediate brand recognition and trust friction for cold visitors and stakeholders who may only see screenshots or the header.

6. UI / VISUAL SYSTEM ASSESSMENT

---

Layout and grid:
- Desktop uses centered max-width workspace with consistent outer padding; home intent cards in responsive grid (3+3+1 orphan seventh card leaves visual hole on wide screens).
- Atlas Map uses two-column split: graph canvas left, coverage matrix right — effective on desktop; collapses to vertical stack on mobile with graph height severely compressed.
- Record detail uses two-column card layout (main + sidebar) on desktop; stacks on mobile.
- Sources and Compare use single-column narrative + card lists — readable.
- VISUAL ISSUE: Seventh home intent card alone on third row breaks grid rhythm and looks unfinished.

Spacing and alignment:
- Generous vertical spacing between page header block (eyebrow + h1 + summary) and content on most routes — occasionally repetitive (Sources, Explore, Compare all use same PageHeader scaffold).
- Record detail action row (Back / Open in Atlas Map / Compare / Copy link) aligns cleanly on desktop.
- Atlas Map: matrix column headers ("Item", "Authority", "Governance...") can visually collide with graph top edge on desktop screenshot — alignment tension between table and diagram regions.
- Mobile: header internal padding causes nav buttons to wrap; inconsistent vertical rhythm between wrapped nav rows.

Typography:
- Body: Public Sans (computed on home).
- Display h1 ~34px on home hero "Control Atlas" — strong hierarchy.
- Eyebrow labels (EXPLORE, ATLAS, TEMPLATES, ABOUT & TRUST) in small caps cyan/teal — consistent accent pattern.
- Section labels (WHAT THIS IS, WHERE IT APPEARS, CONNECTIONS) in tracked small caps — good scanability.
- VISUAL ISSUE: Connection summary line mixes casing ("disa ccis" lowercase in prose, "DISA CCIs" in bold line) — looks like copy-paste inconsistency not design system.
- VISUAL ISSUE: Typo spacing "5 group s" in connection count line.

Color and contrast:
- Background rgb(11,16,32) with slate-100 primary text rgb(248,250,252) — generally strong contrast on headings.
- Primary CTA buttons use blue-to-teal gradient fill — visually distinctive, modern.
- Secondary/outline buttons: white border on dark fill — consistent ghost pattern.
- Atlas nav pill: filled blue even when not current route — reads as primary brand accent but conflicts with nav semantics.
- Provenance legend uses green/orange/gray dots WITH text labels (Official mapping, Inferred / community, Not mapped) — good; not color-only.
- Trust badges ("Used in map: Yes") green pills on source cards — readable.
- Footer disclaimer text small and muted — may approach edge of comfort for long reading at a distance.
- Sidebar muted explanatory text on cards (e.g., source metadata) appears low-contrast gray-on-charcoal — worth formal contrast verification.

Buttons and links:
- Pill radius (~999px) on primary/secondary buttons — consistent family.
- Intent cards use entire card as button with inner title + description + text link — large hit targets on desktop.
- VISUAL ISSUE: Record detail shows four visually similar "Open in Atlas Map" buttons (header row, connections toolbar, sidebar, what-to-do-next) — breaks hierarchy; all compete at same visual weight.
- Text links in cards use cyan accent — consistent with brand accent.

Forms and inputs:
- Search inputs: dark filled field, rounded, magnifier icon inline on Explore — polished.
- Start Here comboboxes: full-width, labeled, disabled state grayed until prior step complete — clear.
- Template filter chips horizontal row — active chip filled blue; inactive outline — clear toggle pattern.
- Header hosts BOTH inline searchbox ("Search records or glossary") AND separate "Open search" button — visually redundant, cluttered header right cluster.

Search and filter controls:
- Explore Refine results collapsible — hidden by default, good progressive disclosure.
- Atlas Map filter checkboxes for supporting/draft/registry sources — small but labeled.
- Sources Refine sources collapsible — consistent pattern.

Graph controls and graph presentation:
- React Flow-style canvas with dot grid, rounded node rectangles, labeled edges ("leads_to").
- Dual zoom control sets observed (Zoom In/Out/Fit View AND Fit to screen/Reset view/Zoom in/out) — visual duplication, cluttered control stack.
- Map legend collapsible button top-right of canvas — appropriate.
- Selected node: blue border highlight on "Control Catalog / Requirement Set" — clear without relying on color alone.
- Mini-map/thumbnail not observed; coverage matrix provides secondary visual encoding.
- Desktop graph readable; mobile graph ~small fraction of viewport after header — visually unusable for relationship comprehension without List tab.

Cards and content blocks:
- Cards use dark charcoal fill, 1px subtle border, ~12px radius, optional left accent bar (cyan on WHAT THIS IS, orange on DISCLAIMER) — distinctive and consistent on About/record pages.
- SummaryCard pattern repeats across routes — cohesive.
- Source cards on Sources page: structured metadata rows, badge top-right — professional.

Panels, modals, and overlays:
- Help/Glossary drawer: slides over content, Close button named, tab interface Help | Glossary — clean.
- Loading panel: centered card with cyan LOADING eyebrow, progress bar shimmer, helpful escape copy — visually on-brand.
- Atlas pull tab: vertical ATLAS label, blue tab on right screen edge — persistent; can overlap scrollbar area.

Imagery / illustration / iconography:
- Tabler-style line icons in nav and intent cards — consistent weight.
- No stock photography — appropriate for technical product.
- Keyboard-key brand treatment in header — unique but visually disconnected from rest of system.

Component consistency:
- PageHeader eyebrow + h1 + summary pattern repeated across Explore, Compare, Templates, Sources, Atlas — consistent but visually repetitive session-to-session.
- Footer three-column grid (Control Atlas / NAVIGATE / LEGAL) consistent on all routes.

Interaction states:
- Nav: underline + aria-current for active route; Atlas pill always filled — inconsistent (CA-WD-002).
- Focus: Skip to workspace link present; keyboard tab order not fully audited.
- Hover: not systematically captured; gradient buttons appear to lighten on hover in screenshots.
- Disabled: Show recommendation button visually muted when incomplete — clear.

Visual polish:
- Subtle background grid on main panels adds depth without noise — polished touch.
- SPA transition flash: previous page content visible briefly after nav click before new view hydrates — feels unfinished.
- Home hero lacks inline search field visible in first paint (search appears in header after load) — minor hierarchy shift.
- Overall: high craft on card surfaces and About page; global chrome and mobile header undermine premium feel.
