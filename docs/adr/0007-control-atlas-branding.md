# ADR 0007: Control Atlas Branding Is The Active Repo Identity

**Status:** Accepted

## Context

The public product direction changed to Control Atlas with the Ctrl+Alt+Comply campaign line and the tagline **The public map for federal cyber compliance.** Epic 0 promotes that branding from a public-copy layer to the active repository, package, and deployment identity.

## Decision

Use **Control Atlas**, **Ctrl+Alt+Comply**, and **The public map for federal cyber compliance.** across public-facing copy, package identity, workflow labels, and deployment references.

## Consequences

The repo must still preserve the static runtime contract and public-data-only boundary while completing the rename. Historical GovFrame evidence remains historical context only.
