# Vendored typefaces

These `.woff2` files are self-hosted so Control Atlas renders the Orbital
Archive No. 01 (v1.8) typography without any external font CDN (the site CSP
allows `font-src 'self'` only). They are wired up in `styles/fonts.css`.

All four families are licensed under the **SIL Open Font License 1.1**
(OFL-1.1), which permits bundling and redistribution with attribution. Files
were retrieved from the Fontsource distribution (`cdn.jsdelivr.net/fontsource`).

| Family | Files | Designer / Source |
| --- | --- | --- |
| Oswald | `oswald-latin-wght-normal.woff2` (variable 200–700) | Vernon Adams, Kalapi Gajjar, Cyreal — Google Fonts |
| Inter | `inter-latin-wght-normal.woff2` (variable 100–900) | Rasmus Andersson — rsms.me/inter |
| IBM Plex Mono | `ibm-plex-mono-latin-{400,500,600,700}-normal.woff2` | IBM / Bold Monday |
| Silkscreen | `silkscreen-latin-{400,700}-normal.woff2` | Jason Kottke |

Full license text: <https://openfontlicense.org/> (OFL-1.1). Each upstream
family ships its own `OFL.txt`; the license is identical across all four.
