# Automation Examples

These scripts illustrate optional automation you can adapt after a project workflow is clear. They are not wired into the template by default.

## Included

- `bootstrap-labels.ts` - example script that bootstraps GitHub labels via the API.
- `create-branch.sh`, `create-issue.sh`, `Init.ps1` - helper scripts for issue-first git workflows.
- `mcp-monitor.js`, `start-mcp-monitor.bat` - sample monitors for MCP tool health.
- `security-scan` - opinionated security sweep script.
- `validate-ticket-headers.js` - example linter for ticket documents.
- `lib/` - supporting snippets for the scripts above.

Adapt or delete these examples when they do not fit the target project. They do not run automatically.
